# Codefinity: Data Types in Python

Exercícios de estudo sobre tipos de dados em Python, organizados por assunto.

## Organização

- `numbers/`: exercícios com números e verificação de tipos.
- `strings/`: exercícios com strings, incluindo concatenação.
- `booleans_and_comparisons/`: exercícios de booleanos e comparações.

Os exemplos fazem parte de estudos no Codefinity e estão distribuídos em pastas de atividades. Não há uma aplicação única neste repositório.
